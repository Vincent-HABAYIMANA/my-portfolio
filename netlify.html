Assignment: Research on Netlify Deployment

Objective

Learn how to deploy a web application using Netlify and prepare a simple deployment guide.

Part 1: Understand Netlify

Research the following topics:

  1. What is Netlify?
  2. What types of applications can be deployed on Netlify?
  3. Advantages of using Netlify.
  4. Difference between Netlify and traditional hosting.

Part 2: Create a Netlify Account

  1. Visit https://www.netlify.com
  2. Create a free account using GitHub.
  3. Explore the Netlify dashboard.

Part 3: Deployment Research

Research and document the steps for deploying a project to Netlify.

Include:

  1. Connecting GitHub repository.
  2. Build command configuration.
  3. Publish directory configuration.
  4. Automatic deployment after Git push.
  5. Environment variables setup.
  6. Custom domain setup (basic overview).

Part 4: Practical Task

Deploy a simple frontend project to Netlify.

Suggested Project Types:

  • HTML/CSS/JavaScript website
  • React app
  • Vue app

Requirements:

  1. Push project to GitHub.
  2. Connect repository to Netlify.
  3. Deploy successfully.
  4. Share deployed URL.

Deliverables

Submit the following:

  1. A short research document (1–2 pages).
  2. Screenshots of deployment steps.
  3. GitHub repository link.
  4. Live Netlify deployment link.

Bonus Tasks

Research the following:

  • Netlify Functions
  • Continuous Deployment (CI/CD)
  • Netlify Forms
  • Deploy previews

Deadline

Complete this assignment within 2–3 days.

Evaluation Criteria

  • Understanding of Netlify concepts
  • Successful deployment
  • Quality of documentation
  • Ability to explain deployment steps
  • Problem-solving during deployment
